# Juego-Vocales
**Creadores:** Brandon Isaac Miranda Montes, Juraz Gael Miranda Coronado y Erick Bustamante Cruz 


Proyecto de diseño UI/UX para un videojuego educativo sobre las vocales. El objetivo es proporcionar una experiencia interactiva y amigable para niños, facilitando el aprendizaje integral de cada vocal mediante módulos de reconocimiento visual, escritura y pronunciación


### 1. Menú Principal y Vocal A
![Captura 2](Captura%20de%20pantalla%202026-09-28%20195129.png)
Pantalla de bienvenida (*"Vocales: Mundo de Burbujas"*) e interfaz didáctica para la vocal **A**, incluyendo su ilustración asociativa (Abeja) y botones de pronunciación.


### 2. Vocales E e I
![Captura 3](Captura%20de%20pantalla%202026-09-28%20195144.png)
Secciones de aprendizaje interactivo para las vocales **E** (elefante) e **I** (iglú), con audio para la letra y la palabra representada.


### 3. Vocales O y U
![Captura 4](Captura%20de%20pantalla%202026-09-28%20195156.png)
Secciones de aprendizaje interactivo para las vocales **O** (oso) y **U** (uvas), manteniendo el mismo sistema visual y auditivo.


### 4. Práctica de Escritura
![Captura 5](Captura%20de%20pantalla%202026-09-28%20195213.png)
Lienzo de trazo manual para cada una de las vocales (*"¡Aprende a escribir la X!"*), equipado con controles para borrar, confirmar la entrega o volver al menú.


### 5. Módulo "Examencito"
![Captura 1](Captura%20de%20pantalla%202026-09-28%20193508.png)
Evaluación interactiva donde se reproduce el sonido de una vocal mediante un botón de audio para que el estudiante identifique y seleccione la opción correcta.
